VINCENT(1)                       User Commands                       VINCENT(1)

NAME
       vincent - founder of ThinkR, builds R and Shiny applications for
       production, trains R users, maintains open source packages

SYNOPSIS
       vincent [--r] [--shiny] [--docker] [--teach] [--package] PROJECT...

DESCRIPTION
       Writes R since 2007, runs it in production ever since. Founded ThinkR,
       a French company that ships Shiny applications, R packages and
       training, and gives most of its tooling back as open source.

       The serious work is not on this account. It is released through the
       ThinkR-open organisation and published on CRAN.

OPTIONS
       --r        writes R, reviews R, reads R at night
       --shiny    Shiny applications that survive their first user
       --docker   containers for everything that must run twice
       --teach    workshops, from "what is a function" to "ship your package"
       --package  turns scripts into packages before anyone asks

PACKAGES
       Maintainer of twelve packages on CRAN, most of them released through
       ThinkR-open:

       attachment(1)    deal with dependencies
       checkhelper(1)   deal with check outputs
       datadiff(1)      data validation based on YAML rules
       fusen(1)         build a package from Rmarkdown files
       shiny2docker(1)  generate Dockerfiles for Shiny applications
       thinkr(1)        tools for cleaning up messy files
       togglr(1)        Toggl.com API for RStudio
       rtodoist(1)      create and manage todo lists with the Todoist API
       fcuk(1)          the ultimate helper for clumsy fingers
       ztype(1)         run a Ztype game loaded with R functions
       rusk(1)          multiplication tables drawn on a modular circle
       spongecake(1)    transform a movie into a synthetic picture

       Co-author of golem(1), a framework for robust Shiny applications,
       and dockerfiler(1), easy Dockerfile creation from R.

BOOKS
       Engineering Production-Grade Shiny Apps, with Colin Fay, Sebastien
       Rochette and Cervan Girard. Chapman and Hall/CRC, The R Series, 2021.
       Free to read online at engineering-shiny.org.

FILES
       ~/VincentGuyader/*
              pet projects, toys and experiments. Written for fun or for a
              single need, none of them is going to CRAN.

       collage         image collages from R
       littleboxes     boxed titles in RStudio scripts

BUGS
       Plenty. This account is a sandbox: use at your own risk. Report the
       serious ones to ThinkR-open, they get fixed there.

LANGUAGES
       French (native), English, R.

SEE ALSO
       thinkr.fr, rtask.thinkr.fr, engineering-shiny.org, ThinkR-open on
       GitHub
